# 3js_3d_window

Phone-as-a-3D-window demo (Three.js + MediaPipe Face Landmarker), hosted on GitHub Pages.

Live: https://randyhaylor.github.io/3js_3d_window/

- Plan: [PLAN.md](PLAN.md) (source brief: [phone_3d_window_demo_plan.txt](phone_3d_window_demo_plan.txt))
- No build step. Serve the folder locally with `python3 -m http.server`.
- Tests: `npm test` (Node 22+, no dependencies)
